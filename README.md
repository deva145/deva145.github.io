# Devanandan A — Portfolio

A bold, interactive personal portfolio built with vanilla **HTML, CSS, JavaScript**, served by a tiny custom **Java** HTTP server.

🔗 Live site: [deva145.github.io](https://deva145.github.io)

## Stack

- **HTML5** — semantic markup
- **CSS3** — gradients, animations, Grid, Flexbox, custom properties
- **JavaScript** — Canvas API particles, IntersectionObserver, custom cursor, 3D tilt, magnetic buttons, text scramble effect
- **Java** — minimal `HttpServer` (no external dependencies) for local serving

## Features

- Animated particle background with mouse-repel physics
- Custom cursor with smooth trail
- 3D tilt-on-hover project cards with cursor-tracked glow
- Text scramble effect, counter animations, magnetic buttons
- Cinematic intro loader and scroll progress bar
- Konami code easter egg with confetti burst (↑↑↓↓←→←→BA)

## Run locally

**With Java:**
```bash
java Server.java
```

**With Python:**
```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.
